先搞懂：Skill 到底是什么 // WHAT IS A SKILL

你可以把 Skill 想成 Claude 的外挂技能包。

原本的 Claude 是通才，什么都懂一点。装了 Skill 之后，等于你给它一份写好的做事方法：什么时候该触发、要照什么流程走、输出要长什么样。它就不用每次靠你重复解释。

没装 Skill：每次都要重新讲一遍你要什么，讲了它还是写得很 AI
没装 Skill：开新对话，之前做过的东西全部忘光
没装 Skill：叫它做界面，做出来的东西一眼就看得出是 AI
Skills 最爽的地方是：装一次，之后一直生效。你不用每次开对话重新教它，它自己知道什么时候该用哪一套方法。

5 个必装 Claude Skills // THE LIST

下面每一个都附上 GitHub 链接，旁边有 COPY 按钮，按一下就可以直接丢进 Claude Code。

01

Stop Slop

用在：文案 / email / caption

让 Claude 写出来的内容更像真人。它会自动拿掉那些一看就很像 AI 写的痕迹，像是破折号、空洞填充句、制式化用语，让文字读起来自然很多。

github.com/hardikpandya/stop-slop https://github.com/hardikpandya/stop-slop
02

Claude Mem

用在：长期项目 / SOP / 团队协作

让 Claude 拥有跨对话记忆。你的项目、文件、之前做过的事情，它都能持续记得。

不用每次开新对话，又把背景全部重讲一遍。

github.com/thedotmack/claude-mem https://github.com/thedotmack/claude-mem
03

UI/UX Pro Max

用在：landing page / app / web redesign

直接帮 Claude 补上一套 UI/UX 脑袋。内建 50+ 种 UI 风格、99 条 UX 设计原则。

让它做出来的界面更像专业设计，而不是一眼就看得出来是 AI 生成。

github.com/nextlevelbuilder/ui-ux-pro-max-skill https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
04

Task Observer

用在：workflow / 自动化 / 个人工作台

默默学会你的工作方式。它会默默观察你平常怎么工作，慢慢学会你的做事方式和偏好。

然后持续优化你其他的 Skills，让整套工作流程越用越懂你。你几乎不用特别做什么，它自己就会越来越聪明。

github.com/rebelytics/one-skill-to-rule-them-all https://github.com/rebelytics/one-skill-to-rule-them-all
05

Find Skills

用在：找工具 / 快速上手 / 不知道装什么

想做什么，它帮你找 Skill。你只要告诉 Claude：「我现在想做什么？」

它就会帮你搜索整个 Skills 函数库，找到最适合的 Skills，甚至直接帮你安装好。

github.com/vercel-labs/skills https://github.com/vercel-labs/skills
!

建议顺序：先装 Find Skills（05），因为之后你想找别的 Skill 它可以直接帮你搜。然后装 Claude Mem（02），让它开始记东西。剩下三个照你的需求装就好。

安装教学：一步一步来 // HOW TO INSTALL

你不需要懂 code，也不需要自己去 GitHub 下载文件。把链接丢给 Claude，叫它帮你打包，你再 upload 进去。

下面分两条路线，看你平常用哪一个。大部分人用路线 A 就好。

路线 A

网页版 Claude（大部分人用这个）

不用装任何东西，浏览器打开 claude.ai 就能做。整个流程是：叫 Claude 打包 → 下载档案 → 去 Settings upload。

1

叫 Claude 帮你打包成 skill 档

CLAUDE.AI

开一个新对话，把下面这段连同 GitHub 链接一起贴进去，按 Enter：

PROMPT · 叫 Claude 打包 skill 档
帮我把这个 skill 打包成可以 upload 的档案：
https://github.com/hardikpandya/stop-slop

请你去看那个 repo 的内容，
把 SKILL.md 和相关文件打包成一个 .skill 档（zip），
然后传给我下载。

打包好之后也告诉我：
1. 这个 skill 叫什么名字
2. 什么情况下它会自动触发
3. 有没有需要我另外设置的东西

把里面的链接换成你要装的那一个就好。上面 5 个 skill 每一个旁边都有 COPY 按钮，按一下就有链接。

!

它可能会先问你几个问题：有些 repo 里面装了不只一个 skill，Claude 会问你要打包哪一个。照它问的回就好，不用紧张。

2

下载它给你的档案

DOWNLOAD

Claude 做完之后会在对话里给你一个档案，通常是 .zip 或 .skill。按一下下载，存在你找得到的地方，等一下要用。

!

手机上做的话：下载下来的档案会在「档案」App 里面。建议这一步用电脑做，upload 的时候比较好找档案。

3

去 Settings 把档案 upload 上去

UPLOAD

回到 Claude 的界面，照这个路径进去：

路径： Settings→ Capabilities→ Skills

在 Skills 那一页找 Upload skill 的按钮，把刚才下载的档案丢进去，等它跑完。

!

找不到 Skills 这个选项？不同版本位置会有一点不一样，有些是在 Settings → Features 底下。直接在 Settings 里面搜「Skill」通常最快。

4

确认它有真的开着

VERIFY

Upload 完不要就这样收工。回到 Skills 那一页看一下，刚装的那个名字要出现在清单里，而且旁边的开关是开着的。

有些 skill upload 完是默认关掉的，你以为装好了其实一直没生效，就是卡在这里。

✓

剩下 4 个照同样流程做：第一步那段 prompt，链接换掉就好。5 个做完大概 5 到 10 分钟。

路线 B

Claude Code（会用 terminal 的看这个）

如果你本来就在用 Claude Code，那更简单，不用打包也不用 upload，一句话叫它自己装。

1

还没装 Claude Code 的先跑这行

SETUP

在 Terminal（Mac）或 PowerShell（Windows）跑：

TERMINAL · 安装 Claude Code
npm install -g @anthropic-ai/claude-code

装好之后，在你想工作的文件夹里打 claude 就可以开始了。

!

如果这一步卡住：通常是电脑还没装 Node.js。去 nodejs.org 装好 Node 再回来跑上面那一行。真的搞不定的话，直接把错误信息截图丢给 Claude，它会告诉你缺什么。

2

把链接贴进对话框，叫它装

INSTALL

打开 Claude Code，把下面这段贴进去，按 Enter：

PROMPT · 叫 Claude Code 自己装
帮我把这个 skill 安装进我的 Claude Code：
https://github.com/hardikpandya/stop-slop

请你自己去看那个 repo 的说明，
把 skill 装到我的 skills 文件夹里，
装好之后告诉我 skill 的名字，
还有什么情况下它会被触发。
✓

它会问你要不要执行：Claude Code 在动你的文件之前会先问过你。看到它要 clone repo、要建文件夹、要写文件，按 yes 让它做完就好。这是正常流程，不是出问题。

3

打 /skills 确认

VERIFY
在对话框打： /skills

会列出你目前所有装好的 skills，刚装的那个应该会在里面。

!

装好了但没反应？先关掉 Claude Code 再重开，很多时候只是它还没重新读取 skills 文件夹。重开之后再打一次 /skills 看看。

两条路线装完之后，记得试跑一次。给它一个刚好会触发那个 skill 的任务，比如装了 Stop Slop 就叫它写一段 caption，装了 UI/UX Pro Max 就叫它做一个 landing page。跑一次你就会明显感觉到跟以前不一样。

装完之后差在哪 // BEFORE / AFTER

同样一句「帮我写这个月的 property caption」，装前装后是这样：

装 SKILLS 之前

  • 写出来一堆破折号，很 AI
  • 每次都要重讲一遍你的项目背景
  • 叫它做页面，做出来很模板
  • 你的偏好它永远记不住
  • 不知道有什么工具可以用

装 SKILLS 之后

  • 文字读起来像真人写的
  • 开新对话它已经知道你在做什么
  • 界面有设计感，不像 AI 生成
  • 用越久它越懂你的做事方式
  • 想做什么，它帮你找工具
✓

一个提醒：Skills 不是装越多越好。装了不用的 skill 只会占位置。先装这 5 个跑一阵子，真的有需要再用 Find Skills 去找别的。
